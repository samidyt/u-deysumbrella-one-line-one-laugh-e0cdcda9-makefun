# One Line, One Laugh

Entry for the [One Line, One Laugh](https://make.fun/bounty/u-deysumbrella-one-line-one-laugh-e0cdcda9) bounty on [make.fun](https://make.fun).

`main.py` writes exactly one funny line to `/output/entry.txt` — a single joke that lands on a cold read, with no setup notes and no explanation:

> My mirror finally told me the truth: 'Objects may appear funnier than they are.' Even my reflection needs a disclaimer.

## Run

```sh
python3 main.py
```

The program validates its own output against the gate (exactly one line, 1–140 UTF-8 characters) before writing it.
